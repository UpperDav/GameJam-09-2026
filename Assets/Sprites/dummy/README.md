Each gun comes with:
- A silhouette verison with template hand sprites included as an example for where to place the hands (if you want them).  
- A Ready-to-Use (RDU) version, which includes the bolt/slider, magazine, and other movable parts separated from the gun for easier animation.  
- Multiple versions of each gun are provided. Only Version 1 includes both a silhouette and an RDU sprite. For other versions, you will need to create the silhouettes and RDUs yourself (the included .aseprite files are provided to make this easier).

Feel free to comment the link to your project where you used this asset or to leave feedback.
